# Panorama con Ro

Página simple para mostrarle los panoramas del viernes y el sábado.

## Estructura

```
index.html
styles.css
script.js
fotos/
  portada.jpg
  viernes.jpg
  playa-negra-1.jpg
  playa-negra-2.jpg
  salinas-1.jpg
  salinas-2.jpg
```

Las 6 fotos ya están puestas (convertidas a `.jpg` y comprimidas) y el número
de WhatsApp ya está configurado en `script.js`. La página está lista para subir.

## Publicar en GitHub Pages

1. Crea un repo nuevo y sube estos archivos a la raíz.
2. Settings → Pages → Source: **Deploy from a branch**.
3. Branch: `main`, carpeta `/ (root)` → Save.
4. En un par de minutos queda en `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`.

Ese link es el que le mandas a Ro.

> Ojo: GitHub Pages distingue mayúsculas de minúsculas en los nombres de
> archivo. Por eso todas las fotos quedaron en minúscula con extensión `.jpg`.
